# What’s been checked

## The tests

The build script compiles for Apple Silicon and Intel, runs the tests, checks the plugin’s signature, and saves a picture of the interface. The tests run on the Mac doing the build, so a successful Intel build still needs a run on an Intel Mac to confirm how it behaves there.

L8BLOOMER’s DSP checks cover exact bypass, swell timing and direction, transient retriggers over continuous input, distorted picks over hum/hiss, onset hysteresis, stereo linking, filter attenuation, extreme automation, gain staging, and block-size independence. Advanced checks cover trigger lockout timing, optional detector filtering, rumble rejection, invalid/crossed detector cutoffs, and session migration.

Frequency-shifter tests measure output frequencies, unwanted-sideband rejection, both sweep directions, stereo behavior, dry/wet mixing, high-frequency alias suppression, and extreme automation across five sample rates. Processor/UI tests check integer knob displays, parameter recall, malformed state, zero latency, exact host bypass, double-click defaults, centered zero, and independent filter/shift parameter storage.

The development v1.3.1 component passed Apple’s strict AU validator after installation. You’ll still want to try it with your own playing in Logic. Heavy compression can hide pick attacks, and playing another note can restart a long swell before it finishes.

The plugin reports zero fixed processing latency. IIR filters still alter phase and have frequency-dependent group delay. Bypass passes original samples unchanged.

Frequency-shifter topology reference: [Olli Niemitalo’s 90-degree IIR allpass pair](https://yehar.com/blog/?p=368). The project’s coefficients were independently generated by `scripts/design/hilbert.py`. NumPy is only needed to regenerate the coefficients, not to build or run the plugin. `build/DspBenchmark` provides an optional local DSP timing comparison.

## Before the first GitHub release — 25 November 2026

Both Mac versions built without compiler warnings, and all the automated tests passed. The installer was checked in temporary folders: installing from scratch, updating with a backup, and refusing to replace an unrelated plugin all worked.
L8BLOOMER also handled the move from the old Slow Bloom name.
